# Linux Day 2

## Commands Learned

### sudo
Runs a command with administrator privileges.

### chmod
Changes file and folder permissions.

### cat
Displays the contents of a file.

### head
Shows the first 10 lines of a file.

### tail
Shows the last 10 lines of a file.

### nano
A terminal text editor used to create and edit files.

### whoami
Displays the current logged-in username.

### history
Shows the list of previously executed commands.
